# 拾取、检视与家具朝向（0.8.1）

对准附近可拾取物体时高亮，按 E 播放拾取动作并收入底部十格快捷栏。靠近不自动拾取，拾取后不自动弹出检视。

数字键 1–9、0 对应十个格子：单按选择，在 0.35 秒内再次按相同键，打开该格物品的 3D 检视。长按键、不同数字键及空格子不触发检视。

书架旁的记录物件也先拾取入栏，再双击检视。关闭该记录的检视时才触发对应书架倒塌，拾取本身不触发。每张记录有独立实例，多个物件共用同一美术/文字素材时也不会一起误触发倒塌。关卡重新进入时可从快捷栏恢复其交互关联。

Tab 显示鼠标后，单击格子选择，左键双击该格也可检视；拖动格子交换物品仍可使用。检视内拖动模型旋转，滚轮缩放，关闭或 Escape 恢复游戏时间。数字键在鼠标模式下同样支持双按。此前的 R/右键检视仍兼容。

独立摆放的 SK_Mannequin 参考人偶在四个游戏场景中设为仅编辑器 Actor，游戏中隐藏、无碰撞，打包时剔除。玩家和怪物角色不受此配置影响。

通过实际源模型四方向渲染，确认书架/沙发正面为本地 +X，抽屉柜/铁柜正面为 +Y。家具按房间内侧确定朝向，侧墙抽屉柜与横向抽屉柜分别适配。修正铁柜横躺问题并恢复白模尺寸。保留 Actor、组件、Actor 原始变换和书架倒塌支点；几何通过逐步逆平移、逆旋转和逆缩放适配原组件，兼容合并场景中的负缩放。

适配工具：Plugins/HorrorSystems/Tools/RepairInteractionArt.py。ApplyArtAssets.py 在导入/替换后调用该适配流程。不要直接旋转整个家具 Actor，否则可能改变交互位置或倒塌支点。

可重复的测试与实际渲染证据见 Deliverables/Verification/InteractionArt。家具渲染检查与控制事件检查使用引擎运行中的实际模型和 Slate 控件；通路测试暂时关闭怪物伤害以单独检查家具碰撞。
