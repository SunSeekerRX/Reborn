# RoomA 玩法测试版 0.6.3

> 历史版本说明。当前 0.7.1 已开放三关完整流程，请按 ThreeStageFlow.md 配置；以下“仅 RoomA、出口关闭”不适用于当前版本。

当前可玩地图只有 Basic_roomA。B、C、ABC 保留现有资源和后续系统代码，但 A 的出口 Actor 的 TravelEnabled 已关闭，拿到关键线索也不会误入未完成房间。后续准备好下一房间后，可以在出口细节面板重新开启 TravelEnabled。

开场镜头曾直线擦进右侧 Cargo rack4 货架。现在使用 WindowSequence 的 CameraWaypoints 绕开它，去程和回程使用同一路线。球体扫掠保护镜头与墙、家具的间距，长帧也逐段访问途经点，避免跳过拐点。起始视角读取角色实际相机，避免重复播放时取到上一次运镜的缓存视角。当前镜头能到达窗边看到怪物，结束后恢复玩家视角与操作。

检视期间仅对玩家自身隐藏身体模型，关闭后恢复此前可见性；拾取动画和正常第一人称身体继续保留。场景内的 SK_Mannequin 静态测试人偶保留为编辑器参考，游戏中不显示、不碰撞。

测试覆盖实际输入的走、跑、斜向移动、Ctrl 慢走、蹲走和恢复；实际出生到大厅的路径；安全屋计时和空气墙；物品检视旋转缩放、暂停与恢复；记录关闭后书架倒塌及落地阻路；挂画交换位置及独占高亮；怪物模型骨架、移动、追逐、扣命和僵直；背景音实际播放与脚步等音频资源引用；超时重新加载 A、物品及书架重置。运镜在实际渲染下分两轮逐帧检测并通过。

已提供素材的家具、屠夫模型和录音继续使用。没有对应家具模型的白模保留；倒塌、换画和落地的专用音效未提供，配置插槽仍为空。
