# Reborn 三关完整流程（0.7.1）

> 三关顺序保持不变。当前 0.8.0 的启动标题、通关返回标题、死亡恢复及第三关安全区/倒塌规则见 TitleRecovery.md；第三关安全区域内现可暂停剩余时间，拿到最终信息前同样禁止正常返程。

## 流程表

| 关卡 | 使用地图 | 目标及下一步 |
|---|---|---|
| 第一关 A | Basic_roomA | 从 A 安全屋出发，取得钥匙，返回 A 安全屋，白光门传送到 B 安全屋 |
| 第一关 B | Basic_roomB | 首次进入播放现有窗边过场；取得钥匙并返回 B 安全屋，立即结束第一关、进入第二关 |
| 第二关 C | Basic_roomC | 从 B 安全屋白光门传送到 C，取得 C 线索，返回 C 安全屋后传送到 B |
| 第二关 B | Basic_roomB | 取得本关 B 线索，返回 B 安全屋后传送到 A；不重复第一关过场 |
| 第二关 A | Basic_roomA | 取得本关 A 线索，返回 A 安全屋，立即结束第二关、进入第三关 |
| 第三关 ABC | Basic_roomABC（实际资源 Basic_roomABC_unchange1） | 从大地图 A 安全屋出生，在 A 取得最终信息，沿相连 A/B/C 跑到地图远端出口；进入出口产生白光，显示 REBORN 标题和重新开始按钮 |

第二关的三个线索按房间分别记录，第一关钥匙不会满足第二关的线索要求。跨关保持已有物品与生命。全流程从第一关 A 开始，共五次跨地图传送；第三关内部连续跑动，不用传送代替穿越大地图。

## 安全屋、时间与阶段

第一、二关每个房间独立提供 60 秒。安全屋内不计时；角色完全离开安全区域后开始计时并启用空气墙。取得当前房间关键物品后，空气墙解除、任务改为“赶紧返回安全屋”，但倒计时继续。回到安全屋才停止计时并打开白光门。

第一关 B 和第二关 A 的阶段切换就在返回安全屋时执行。管理器保存该次已完成房间的出发路线，阶段改变后仍能使用已打开的门，不会被新阶段线索重新锁住；同一安全屋内也不会再次启动计时。下一次实际切图后，才初始化目的房间的新线索和倒计时。

第三关暂沿用 60 秒预算：离开 A 安全屋开始计时，进入 B/C 区域不会重置；取得最终信息后提示“前往地图末端的最终出口”。第三关安全区域不产生挡路空气墙，允许通过原有相连通道。超时仍回滚至第三关 A 安全出生点、撤销本次取得的最终信息。若后续决定第三关不限时，应单独调整这一规则。

检视继续暂停世界时间，关闭后恢复；白光切图期间锁定操作并覆盖源、目的地图，加载较慢时会停留白屏更久。完成后的标题是现有结束界面，不额外切换到未经制作的菜单地图。“重新开始”清空进度并回到第一关 A。

## 编辑器资源

- 独立地图管理器使用 DA_SafeTravelRoomA/B/C，Return To Safe After Objective 开启。
- 新占位门为 Reborn_SafePortal_A/B/C。原大厅出口保持关闭，原房屋和家具模型不替换。
- 路线的 Advance On Safe Return：仅 B 的 Stage 1 和 A 的 Stage 2 开启。Advance Stage 不启用，避免进入门时重复加关卡。
- 白光门的出生标签按实际路线 Target Room 自动选择 Safe_A / Safe_B / Safe_C。
- B 的 Play First Entry Sequence 开启，A/C 关闭。SeenWindows 跨地图保存，第二关 B 不重复播放。
- ABC 使用一个 Final Escape Mode 管理器，Safe_A 出生。DA_FinalInformation 为最终信息的占位物品资源，模型暂沿用已有道具模型，名称/说明独立可改。
- Reborn_FinalExit 新增在大地图末端走廊，当前位置 (-200, -8900, 250)，取得 Key_3 才开启白光，进入后完成游戏。
- ConfigureSafeTravel.py 是当前配置工具，执行前备份至 Saved/Verification/BeforeThreeStageFlow，保留原房屋和家具。它会调整本工具新建钥匙的落点到可行走区域，清理上一版工具新建的第三关分房间计时管理器和 B/C 占位线索。

## 验证方法

SafeWhiteTravel 连续测试 A1→B1→C2→B2→A2→ABC3，检查 B 过场、两次返回安全屋即时切换阶段、白光门实际移动触发、加载遮挡和正确出生点。

FinalEscape 在 ABC 中检查最终信息前出口锁定、拾取后解锁，扫描角色胶囊可通行路线，然后以实际移动和 Shift 输入跑完整段相连地图，检查白光结束和标题状态；测试中暂停怪物伤害以隔离通路验证。另重复移动、3D 检视和超时回滚。详细证据见 Deliverables/Verification/ThreeStageFlow。
