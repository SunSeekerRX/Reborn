# Basic场景交互适配 Implementation Plan

**Goal:** 以Basic A/B/C及ABC为准，接入已有第一人称、安全屋、怪物、3D检视，并加入倒塌障碍、挂画交换和独占高亮。

**Architecture:** 独立交互Actor提供倒塌、检视触发及挂画配对动画；角色统一选择焦点并渲染一个高亮。房间管理器按玩家所在区域选择当前房间，门户支持独立地图及组合地图内传送。音效采用可配置的空资源引用。

**Tech Stack:** UE5.8 C++、Slate、Editor Python、原有HorrorSystems插件。

**Constraints:** 保留用户制作的几何和家具；检视暂停世界；关闭后才倒塌；倒塌碰撞更新导航；仅一个可见高亮；普通拾取黄色、挂画蓝色；不新增音效文件；旧Test地图归档不删除；不推送Git。

- [x] 统一交互焦点：视线、距离、遮挡检查，选择绘画优先级，独占高亮材质。
- [x] 倒塌障碍与检视触发：关闭事件绑定、底部旋转支点、落地碰撞、音效空槽。
- [x] 挂画配对：E记录第一张，同组第二张交换、动画期间锁定、蓝色独占高亮、音效空槽。
- [x] Basic地图适配：房间规则、安全屋、地图/本地传送、导航、追逐怪物、窗外近距离演出、交互样例。
- [x] 音效配置：步行与跑步分别配置、落地/倒塌/交换资源留空。
- [x] 验证：实际Basic地图中检视暂停与关闭触发、倒塌后的碰撞阻路、挂画交换坐标及独占高亮；编辑器和游戏编译；截图检查。
