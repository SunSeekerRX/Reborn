# 三房间阶段系统

采用独立的 GameInstance 阶段子系统保存跨关卡进度，每张地图放一个 RoomDirector，负责安全区、计时和窗户首次演出。数据资产为三个阶段分别配置目标房间、关键线索和最终出口，可在 UE 中替换正式房间。

- 默认 A→B→C→A，C→A 推进阶段；第三阶段 C 出口触发白光与结束界面。
- 每次进入房间获得独立 60 秒预算。在玄关和首次运镜期间冻结；完全走出玄关后开始计时，空气墙开启。检视暂停世界与倒计时。
- 超时撤销本次房间内新增物品和线索，三个预算重置；重载当前房间，在玄关复位。此前房间的物品和线索保留，首次演出不重复。
- 左上显示本房间当前阶段的关键线索状态；门锁具有碰撞，取得全部关键线索才能通过。第一人称拾取动作与暂停检视分开，先播放动作后按配置检视。
- 怪物追踪保留导航路径实时更新，新增慢/普通/快三档与空间脚步/呼吸音；在玄关、演出和结束时暂停追踪。不实现杀死玩家。
- 可交互物件用可配置局部位移/旋转完成开合或移动，可作为线索。
- 窗户演出提供镜头移入、上下黑边、窗外慢走/看向玩家/快速离场及镜头返回。

执行顺序：回归移动 → 编写进度与回滚测试 → 子系统/门锁/安全区 → HUD → 交互与动画/音效 → 窗户白模与演出 → 真实关卡自动化与渲染检查 → 更新文档及可迁移插件。此次修改保留旧版本交付压缩包作为备份。

验证重点：WASD/斜向速度/奔跑/慢走/蹲起/碰撞；玄关不计时、离开不可返回；锁门、三阶段连通关系；跨图线索持久化、超时仅清理当前房间新增内容；暂停计时；首次演出恢复输入；通关白光；原有十格容量与检视拖动。
