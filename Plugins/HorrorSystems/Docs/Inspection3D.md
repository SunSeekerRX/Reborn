# 3D物品检视

选中物品后按R，或拾取自动检视的物品，会显示真实静态网格模型。检视区域宽高随游戏窗口调整，约占屏幕的三分之二。模型周围完全透明，没有上方背景框和全屏遮罩；仅底部文字面板有半透明背景。左键拖动可沿水平和垂直方向旋转，滚轮缩放，左键双击复位。关闭按钮或Esc退出。游戏时间、倒计时和怪物仍暂停，预览操作继续响应。

在物品数据资产HSItemData的“Inspection 3D”分类配置：

- Inspection Mesh：需要显示的静态网格模型。
- Inspection Materials：可选材质覆盖，数组顺序对应模型材质槽。
- Inspection Scale：模型缩放。
- Inspection Rotation：打开检视时的初始朝向。

纸条、旧钥匙、电池和徽章已配套测试模型。纸条的原2D图作为模型表面材质保留，旋转后能查看纸片厚度及背面。未指定模型的旧物品暂用立方体占位，需要在数据资产中指定正式模型。

预览采用运行时独立FPreviewScene和SceneCapture2D，不放入实际关卡，不依赖UnrealEd。HDR捕获的反透明度通过UI材质转换为物品轮廓透明度。捕获分辨率和相机距离随预览区域调整，避免不同窗口比例拉伸模型。只在打开、旋转、缩放或改变窗口尺寸时更新捕获，关闭后释放预览场景和渲染目标。所有代码、配置和模型均在HorrorSystems插件内。
